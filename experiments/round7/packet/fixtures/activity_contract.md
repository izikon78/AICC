# Complete intended behavior for the activity rollup task

`rollup_activity(events, window_seconds=600, min_severity=0)` returns a deterministic list of event groups. Input is a list of dictionaries. Invalid event entries are silently skipped. An event is valid if it has a nonblank string `event_id`, `device`, and `kind`; a string `message`; a nonnegative integer `timestamp` (booleans are invalid); and a case-insensitive severity of `info`, `warning`, or `critical`. Normalize `device` and `kind` with trim + lowercase, and `message` by collapsing internal whitespace. Normalize IDs by trimming. Severity scale is info=0, warning=1, critical=2. Ignore events whose severity is less than `min_severity`. Reject invalid `window_seconds` (must be strictly positive integer, not bool) and invalid `min_severity` (integer 0,1,2, not bool) with ValueError. Reject non-list `events` with TypeError.

Sort valid events by `(timestamp, event_id)`. Group by `(normalized device, normalized kind, normalized message)`. Maintain the most recently accepted timestamp in each active group. Merge the next matching event into the current group when its timestamp is at most `window_seconds` after that most recently accepted timestamp; otherwise begin a new group. The group records `device`, `kind`, `message`, `first_timestamp`, `last_timestamp`, highest `severity`, `count`, and `event_ids` in processing order. Return groups ordered by `(first_timestamp, device, kind, message)`. No external effects. No mutation of input data is intended.

This contract is a human-readable research fixture. Its completeness is not a general proof of a reusable capability's correctness. In real systems, tests and runtime policies remain necessary.
