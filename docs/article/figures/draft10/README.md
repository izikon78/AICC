# Draft 10 figures from the approved-core test

These assets use only the latest approved-core accounting and its submitted
independent reconstructions. No earlier interpreter, processing or prompted
fluency performance figures are mixed into this dataset. All source identities
are recorded in chart-data.json. PNG and SVG versions carry identical data.

Python text tokens are tokenizer measurements. Ideal AIN, ideal IR and ideal
Python units are modeled and equal by construction. Comparisons assume equal
cost per position, fluent learned vocabulary, approved shared components and
correct supplied composition. There are zero experimental model inference calls.

The 144 semantic stage records are 72 per data schedule, reusing three domain
templates and six variants each. Five profiles times three turns produce 2,160
accounting rows, not 2,160 independent model trials. Claude's sensitivity changes
are separately labeled extensions to the frozen result. Grok is pending and is
stored as ??, never as a measured zero or an additional agreeing replication.

CSV files provide the exact inputs to the three charts. agent-comparison.json
preserves the Codex and Claude reproduction statuses, including their different
reference-package test counts and Claude's tokenizer-acquisition deviation.
