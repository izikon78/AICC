# Draft 11 branch and experiment review

Review date 7 November 2026. This package records the review supporting Draft 11.
The snapshot covers all fourteen published remote branch tips present when the
review began, plus the two saved local RTX 3080 adaptation/compiler studies.

`branch-snapshot.json` records branch tips, file counts and experiment families.
`experiment-files.csv` lists 5,859 evidence entries with their branch, tip, Git
blob and path. There are 796 distinct evidence blobs across those entries.
Inherited or relocated copies are the same evidence. The new article branch
contains the review output and the previously local study sources/results.
