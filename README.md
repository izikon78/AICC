# AIN and AICC

Research into how AI agents can create, change and reuse computation through a
learned representation and approved shared capabilities.

**AIN is the reference concept AI Native Language. AICC means AI Computational Commons.** Concept,
architecture and research direction belong to **Izik Bachar**. This final-draft
publication is on `codex/ain-final-draft` and is dated 8 November 2026.

The article starts from the theory that an optimized language is already fluent
and reusable core code is approved. It develops the approach through C#, Python,
C++, Ruby and Java examples, then separates measured processing and adaptation
results from conditional workflow accounting.

The approved-core calculation finds 24.0% fewer counted positions with resident
data and 12.8% fewer with data in context. It also assumes correct composition
and equal cost per position. Equivalent ideal Python and IR interfaces tie with
AIN. Actual learned-agent efficiency is the next research question.

## Reproduce the final experiments

Begin with [testing instructions](publication/reproduction/START_HERE.md) or
[download the portable test package](publication/downloads/AICC_Final_Experiments_Packet.zip).
The primary CPU route replays the approved-core calculation using pinned
packages and bundled tokenizer assets. An independent route reconstructs the
accounting before expected-output comparison. Compiler, processing and GPU
adaptation routes have separate dependency and resource requirements.

Readers who have seen the article's totals should disclose that exposure when
reporting an independent reconstruction. Preserve first outputs and all failed
attempts. The [publication validation](publication/VALIDATION.md) records checks
and output identities.

The next study measures build, change, repair and handoff on reserved structures
with matched compact Python, IR and AIN agents. Its proposed budgets, correctness
criteria and scaling decisions are specified in the research programme.
