## Rebuild

The focused CPU routes are in [the current testing guide](reproduction/START_HERE.md).
Use separate environments for accounting, plotting and GPU adaptation. From the
repository root, the final artifact builders are,

```text
python tools/build_final_figures.py
python tools/build_final_article_pdf.py
python tools/build_final_research_packet.py --overwrite
```

The plotting environment uses Matplotlib 3.11.2. The PDF uses ReportLab with Arial
and Consolas installed on Windows. A rebuild that changes bundled bytes requires
new output hashes and a refreshed archive validation record. Editable Markdown
is the authoring source.
